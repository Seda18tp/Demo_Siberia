# Siberia GastroBar - Plantilla
## ¿Qué contiene esta plantilla?
- **index.html**: Sitio web comercial responsivo con diseño moderno en modo oscuro (Dark Mode), paleta ámbar y dorada, catálogo de platillos destacados, integración de reservas directamente a WhatsApp y enlace al sistema POS GastroSoft.
- **Tecnologías utilizadas**: HTML5, Tailwind CSS (vía CDN), FontAwesome Icons y Google Fonts (Playfair Display & Plus Jakarta Sans).

## ¿Cómo montarla en tu servidor local (XAMPP)?
1. Copia toda esta carpeta dentro de tu ruta de XAMPP:
   `C:\xampp\htdocs\gastroSoft`
2. Abre el XAMPP Control Panel y enciende el servicio **Apache** (botón Start).
3. Abre tu navegador e ingresa a:
   `http://localhost/gastroSoft/`

¡Listo! Ya tienes la cara comercial de tu negocio lista para mostrar a clientes, profesores o evaluadores.
